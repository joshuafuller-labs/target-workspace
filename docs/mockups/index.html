Same data model

Targets, sources, publishers, promotion policies, audit log — identical across all four mockups. Only the board template, default columns, and aesthetic shift per workspace.

Self-contained

Each file is one HTML doc — Tailwind CDN, Google Fonts, custom CSS and vanilla JS only. No build step. Open from disk or this LAN server.

Tooltips everywhere

Hover any chip, control, card row, column header, glyph, or status indicator. Designed for operators who need to learn the system without losing what they're looking at.
